# Задание 1

## Задача 1

### Текст задачи
Составить описание класса с тремя целочисленными полями. Предусмотреть конструктор по умолчанию, конструктор с параметрами и конструктор копирования. Реализовать свойства для доступа к полям. Разработать метод, вычисляющий минимальную из последних цифр полей.
Разработать дочерний класс, представляющий тройку чисел как Дату (День, Месяц, Год). Переопределить свойства с валидацией диапазонов (день от 1 до 31, месяц от 1 до 12, год — положительное число). Реализовать метод проверки года на високосность и метод получения даты следующего дня. 
Обеспечить интерактивный ввод данных с клавиатуры с проверкой корректности.

### Алгоритм решения
1. **Базовый класс (`ThreeIntFields`):** Создаются три автосвойства `First`, `Second`, `Third`. В методе `GetMinLastDigit()` с помощью остатка от деления на 10 (`Math.Abs(value) % 10`) выделяются последние цифры каждого числа. Сравнением `if-else` находится минимальная из них.
2. **Дочерний класс (`DateTriple`):** Переопределяет работу с полями через свойства `Day`, `Month`, `Year`, куда встроена проверка `throw new ArgumentException()` при выходе за рамки допустимых значений.
3. **Метод `GetNextDay()`:** Берет массив дней в месяцах. Если месяц февраль и год високосный, максимальный день равен 29, иначе берется значение из массива. К текущему дню прибавляется 1. Если день превысил максимум, он сбрасывается в 1, а месяц увеличивается. При превышении 12 месяцев увеличивается год.
4. **Валидация:** Метод `int.TryParse` используется в цикле `while` для защиты от ввода букв. Повторный ввод даты запрашивается, если сгенерировано исключение `ArgumentException`.

# Задание 2 и 3

### Текст задачи
**Задание 2:** Разработать класс `QuadraticEquation`, представляющий квадратное уравнение вида $a \cdot x^2 + b \cdot x + c = 0$. Реализовать поля, свойства с валидацией старшего коэффициента ($a \neq 0$), конструкторы (по умолчанию, параметризованный, копирования) и перегрузку `ToString()`. Разработать метод `GetRoots()`, возвращающий массив корней типа `double` (от 0 до 2 элементов в зависимости от дискриминанта). Обеспечить проверку ввода.

**Задание 3:** Добавить в класс перегруженные операции:
* Унарные `++` и `--` (изменяют коэффициенты на 1).
* Операции приведения типов: неявная в `double` (возвращает дискриминант) и явная в `bool` (true, если корни существуют).
* Бинарные операции `==` и `!=` (равенство по совпадению коэффициентов).

### Алгоритм решения
1. **Валидация коэффициента $a$:** В параметризованном конструкторе проверяется условие `if (a == 0)`. Если оно истинно, генерируется `ArgumentException`, так как уравнение перестает быть квадратным. Безопасный ввод `ReadDouble` на этапе работы `Main` физически не позволяет пользователю отправить 0.
2. **Поиск корней (`GetRoots`):** Сначала рассчитывается дискриминант $D = b^2 - 4ac$. 
   * Если $D < 0$, возвращается пустой массив `new double[0]`.
   * Если $D == 0$, возвращается массив с одним корнем: $\frac{-b}{2a}$.
   * Если $D > 0$, рассчитываются два корня с использованием `Math.Sqrt(d)` и возвращаются в массиве из двух элементов.
3. **Перегрузка операторов:**
   * Операторы `++` / `--` возвращают новый объект `QuadraticEquation`, где к каждому коэффициенту прибавлена/вычтена единица.
   * Ключевое слово `implicit` используется для автоматического преобразования уравнения в `double` (возврат дискриминанта), а `explicit` — для принудительного каста в `bool` (`Discriminant >= 0`).
   * Операторы `==` и `!=` сравнивают между собой по отдельности свойства `A`, `B` и `C` двух объектов с предварительной проверкой на `null`.
